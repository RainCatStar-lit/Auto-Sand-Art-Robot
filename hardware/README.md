# hardware — 硬件选型与接口说明

> 嘉立创 EDA 专业版双层板工程、原理图、PCB、BOM 存放于本目录。  
> 主控：ESP32-S3-WROOM（Arduino 框架，`millis()` 轻量多任务 + 状态机，**不使用 FreeRTOS**）。  
> 机械配合见 `docs/DESIGN.md`，引脚定义见 `hardware/pinout.md`，电路原理见 `docs/CIRCUIT_DESIGN.md`。

---

## 0. 选型总则

![Toolhead Diagram](喷嘴设计_锥形阀.png)

- 全部执行器与传感器接口按“**固定端承重、移动端轻量**”原则分配：电磁铁、震动马达（工具头端）随龙门移动；SG90 舵机随横梁挂载；HX711、料盒一级破拱马达、电源与主控固定于机架。
- 粉体隔离优先：电磁铁推杆穿入阀腔处必须加 O 型密封圈 / 硅胶波纹管（机械结构见 `docs/DESIGN.md` §3.2），电子侧只做驱动与检测，不接触沙粒。
- 感性负载（电磁铁、震动马达）一律 NMOS 低边驱动 + 续流二极管 + TVS，PWM 走线远离 HX711 与 UART 信号线。

## 1. 执行器

### 1.1 12 V 推拉式电磁铁（锥形阀驱动）

| 项目 | 规格 / 要求 |
|------|-------------|
| 类型 | 12 V 推拉式电磁铁（solenoid），**贯穿式推杆** |
| 行程 | 3～5 mm |
| 安装 | 垂直安装，推杆朝下，末端连接 30°～60° 锥形硅胶软塞 |
| 保持方式 | 断电弹簧自锁：断电后硅胶塞被弹簧压紧 2.5 mm 倒圆锥喉部，零漏沙 |
| 驱动 | NMOS 低边驱动（IRF520N 或等效逻辑型 NMOS），栅极 100 Ω + 10 kΩ 下拉，线圈两端反并联续流二极管（1N4007/SS34），漏源间 TVS（SMBJ15CA） |
| 控制 | ESP32-S3 LEDC PWM（5 kHz / 10 bit），占空比 0～1023 线性对应吸合力度 |
| 接口 | PH2.0-2P 电源 + PH2.0-2P 信号；线束随工具头移动，套硅胶软管保护 |

> 电磁铁发热会导致 PWM 特性漂移（风险 R-01）：连续出沙 > 20 min 需降额或加散热片，固件侧做温度补偿。

### 1.2 微型震动马达（破拱 / 流化）

| 项目 | 规格 / 要求 |
|------|-------------|
| 类型 | 微型扁平震动马达（coin 型） |
| 电压 | 3 V～5 V（板载 5V 经 NMOS 低边 PWM 调速） |
| 一级破拱 | 固定于料盒 60° 漏斗外侧，震散漏斗壁结拱 |
| 二级破拱 | 贴于工具头外壳侧面，配 TPU 减震垫，负责阀腔顶部流化 |
| 驱动 | NMOS 低边驱动，负极就近加 0.1 µF 去耦电容，抑制 PWM 纹波回耦逻辑地 |
| 控制 | ESP32-S3 LEDC PWM 调速；关阀前 100 ms 满功率脉冲（防拖尾时序，见 `docs/DESIGN.md` §4） |

### 1.3 SG90 微型舵机（刮板升降）

| 项目 | 规格 / 要求 |
|------|-------------|
| 类型 | MG90S 金属齿轮舵机 |
| 安装 | 刮板支架（`Squeegee_Holder`）上，独立挂载于龙门横梁后方 |
| 信号 | 50 Hz / 500～2500 µs PWM，ESP32-S3 LEDC 通道直驱 |
| 供电 | 5 V（舵机单独供电，信号地与逻辑地共地） |
| 功能 | 转 90° 时实现喷嘴 Z 轴下降+刮板抬起（出沙模式）；转 0° 时实现喷嘴抬起+刮板降下（找平模式）。共享单一舵机完成 Z 轴升降与刮板互斥动作，无需额外 Z 轴电机或独立 SG90 舵机。 |

## 2. 传感器

### 2.1 红外槽型光耦（IR Slot Sensor，堵料检测）

| 项目 | 规格 / 要求 |
|------|-------------|
| 型号 | TCST1103 或等效槽型光耦 |
| 用途 | 工具头喷嘴旁侧，检测砂流通过/阻断；堵料或无砂流时输出跳变，触发堵料保护 |
| 数量 | **≥ 2 路**（工具头 1 路 + 料盒/软管出料端 1 路） |
| 接口 | GPIO 输入（数字或 ADC），板载 10 kΩ 上拉，阈值标定：有遮挡/无遮挡 ADC 差值 > 2000 |
| 供电 | 3V3，信号线短走线 + 地填充屏蔽 |

### 2.2 HX711 + 1 kg 称重模块（闭环流量标定）

| 项目 | 规格 / 要求 |
|------|-------------|
| 组成 | HX711 24 bit ADC + 1 kg S 型称重传感器 |
| 安装 | 回收盒底部（固定端），机械限位挡块防过载（实际载荷 < 300 g） |
| 用途 | 闭环流量标定：多点 PWM 出沙 → 质量增量拟合流量曲线 → 查找表烧录 Flash；**亦可间歇性检测堵料**（单位时间质量增量低于阈值即判定堵料/断流） |
| 接口 | E+ / E- / A+ / A- 接传感器；DT → GPIO 12，SCK → GPIO 13 |
| 滤波 | 200 样本滑窗均值 + 板载 NTC 多项式温漂补偿 |

## 3. 主控与 PWM / GPIO 规划

主控 **ESP32-S3-WROOM**，Arduino 框架。执行器 PWM 使用 LEDC 外设分配通道，传感器占用独立 GPIO：

| 功能 | 器件 | GPIO / LEDC | 方向 | 备注 |
|------|------|-------------|------|------|
| 电磁铁驱动 | 12 V 推拉电磁铁 | GPIO 14 / LEDC CH0 | 输出 | NMOS 低边，5 kHz / 10 bit |
| 震动马达驱动 | 微型扁平马达 ×2 | GPIO 15 / LEDC CH1 | 输出 | NMOS 低边，PWM 调速 |
| 刮板升降 | SG90 舵机 | GPIO 20 / LEDC CH2 | 输出 | 50 Hz，500～2500 µs |
| 堵料检测 1 | 红外槽型光耦 | GPIO 18 | 输入 | 工具头喷嘴旁 |
| 堵料检测 2 | 红外槽型光耦 | GPIO 21 | 输入 | 料盒/软管出料端 |
| 称重数据 | HX711 DT | GPIO 12 | 输入 | 回收盒底部 |
| 称重时钟 | HX711 SCK | GPIO 13 | 输出 | — |
| 限位 X / Y | 微动开关 | GPIO 16 / GPIO 17 | 输入 | 上拉，中断触发 |
| 急停 | 蘑菇头按钮 | GPIO 19 | 输入 | 上拉，最高优先级，硬件级切断驱动 EN |

> PWM 通道规划：CH0 电磁铁、CH1 震动马达、CH2 舵机；后续如需流量微调可扩展 CH3 给二级震动马达。红外检测占用 ≥ 2 个 GPIO（GPIO 18 / GPIO 21），满足堵料双点冗余检测。

## 4. 电源树

| 网络 | 电压 | 供电对象 | 备注 |
|------|------|----------|------|
| VIN | 24 V | TMC2209 ×2 VM（步进电机） | 主电源输入，5A 贴片保险丝 |
| 12 V | 12 V | 电磁铁线圈 | 板载 DCDC 24V→12V（MP2307 / XL1509） |
| 5 V | 5 V | SG90 舵机、震动马达 | 板载 DCDC / LDO |
| 3V3 | 3.3 V | ESP32-S3 核心、HX711、红外对管逻辑 | LDO 5V→3.3V |

## 5. 机电接口定义（板级连接器）

| 连接器 | 规格 | 连接对象 | 位置 |
|--------|------|----------|------|
| J1 | PH2.0-2P | 电磁铁线圈 | 板载 → 工具头线束 |
| J2 | PH2.0-2P | 震动马达（工具头端） | 板载 → 工具头线束 |
| J3 | PH2.0-3P | 红外对管 ×2（VCC/GND/OUT） | 板载 → 工具头 / 料盒 |
| J4 | PH2.0-4P | HX711 DT/SCK/E+、E- | 板载 → 回收盒底部 |
| J5 | PH2.0-3P | SG90 舵机（VCC/SIG/GND） | 板载 → 刮板支架 |
| J6 | XH2.54-4P | TMC2209 UART ×2 | 板载 → 驱动座 |
