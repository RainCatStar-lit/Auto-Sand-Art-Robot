# 电路设计原理说明（嘉立创 EDA 双层板）

> 项目：Auto-Sand-Art-Robot（星火计划悬赏赛道）  
> 板层：双层板（Top + Bottom，1.6mm）  
> 主控：ESP32-S3-WROOM  
> 作者：RainCatStar（广东实验中学 SSIR 机器人社高二学生）  
> 状态：第一版原理图，边学边画，难免有坑，欢迎拍砖

---

## 0. 先说清楚：我能画什么，目前还不能画什么

这是我第一次用嘉立创 EDA 画 PCB。之前没碰过任何 EDA 软件，更没画过双层板。这份文档不是一份成熟的工程设计规范，而是我**边学边画、边踩边改**的笔记。

电路方案的核心原则：**大电流部分（24V 电机、12V 电磁阀）和小信号部分（3.3V ESP32、HX711 称重）尽量分开，单点接地，避免地弹跳导致 ESP32 乱复位。**

下面按功能块拆解，每块都写清：接什么、为什么这么接、双层板要注意什么。

---

## 1. 电源树：24V 主输入，多级降压

整机只接一个 24V 电源适配器，板载多级降压给不同模块供电。

```
24V DC IN (DC 插座 / PH2.0-2P)
    │
    ├─→ 5A 贴片保险丝 (F1) ──→ 防止短路烧板
    │
    ├─→ TMC2209 ×2 VM 引脚 (24V 直供)
    │     └─→ 步进电机 (X/Y 轴)
    │
    ├─→ 电磁阀驱动 NMOS 漏极 (12V 需要)
    │     └─→ 板载 DCDC 24V→12V (预留 MP2307 / XL1509)
    │           └─→ 12V 电磁阀线圈
    │
    ├─→ 震动马达驱动 (5V 或 12V，预留)
    │     └─→ 板载 LDO/DCDC 24V→5V
    │
    └─→ ESP32-S3 最小系统 + 逻辑电平
          └─→ 板载 LDO 5V→3.3V (预留 XC6206 或等效)
                └─→ ESP32-S3 核心、HX711、传感器逻辑
```

### 为什么这么设计

- **24V 电机直供**：步进电机需要大电流，直接接 24V 主电源，不经过降压，减少发热和压降。
- **电磁阀专用 12V**：电磁铁额定 12V，直接接 24V 会烧线圈，必须板载 DCDC 把 24V 降到 12V。
- **逻辑 3.3V 独立**：ESP32-S3 核心、HX711、红外对管等小信号模块用 3.3V，通过 LDO 从 5V 降压，与大电流部分电气隔离，减少干扰。

### 双层板走线提醒

- 24V 和 12V 电源走线要走宽（建议 ≥ 0.5mm），回路尽量小。
- 电源输入口旁加 100μF 电解电容 + 0.1μF 瓷片电容去耦。
- 大电流回路（电机、阀门）不要和 3.3V 信号线并行太近，防止电磁干扰。

## 2. ESP32-S3 最小系统

ESP32-S3-WROOM 模块，集成 Flash 和天线，外围只需要最小系统：

| 引脚 | 连接 | 说明 |
|------|------|------|
| 3V3 | LDO 输出 | 核心供电 |
| GND | 地平面 | 单点接地 |
| EN | 上拉 + 复位按钮 | 芯片复位 |
| GPIO 0 | Boot 按钮 + 上拉 | 进入下载模式 |
| GPIO 1 | USB TX | 串口调试 / 烧录 |
| GPIO 3 | USB RX | 串口调试 / 烧录 |
| GPIO 2 | 状态灯 (LED/WS2812) | 运行指示 |
| IOREF | 3.3V | IO 电平参考 |

### 双层板走线提醒

- USB D+/D- 如果走板上走线，要走短，走顶层，下面铺完整地平面，不要和 24V 电源走线并行。
- 复位按钮和 Boot 按钮加 10nF 去电容消抖。

---

## 3. 步进驱动 TMC2209 ×2（CoreXY）

双电机驱动 X 轴和 Y 轴，UART 模式配置，静音且支持传感器less 回零。

| TMC2209 引脚 | 连接 | 说明 |
|-------------|------|------|
| VM | 24V 主电源 | 驱动电机 |
| GND | 地平面 | 共地 |
| 1A/1B, 2A/2B | 步进电机 A+/A-/B+/B- | 电机绕组 |
| EN | GPIO 8（共用） | 两颗驱动使能共用一根 GPIO |
| UART TX | GPIO 4 (X) / GPIO 6 (Y) | 发送到 ESP32 |
| UART RX | GPIO 5 (X) / GPIO 7 (Y) | 从 ESP32 发送 |
| DIAG | 悬空或接 GPIO | 预留故障诊断 |
| MS1/MS2 | 接地或上拉 | 微分步设置，UART 模式下通常不接 |

### 双层板走线提醒

- UART 信号线（TX/RX）走短，远离 24V 电机走线，防止串扰导致失步。
- 电机四根线 (1A/1B/2A/2B) 成对走线，不要和信号线捆绑。
- 每颗 TMC2209 旁边加 10μF 电解电容滤除电机启动时的电压波动。

---

## 4. 称重模块 HX711 + 1kg 传感器

安装在台面下方回收盒底部，用于称重闭环流量标定。

| HX711 引脚 | 连接 | 说明 |
|-----------|------|------|
| VCC | 3.3V 或 5V | 供电（3.3V 足够，减少干扰） |
| GND | 地平面 | 共地 |
| DT (DOUT) | GPIO 12 | 数据输出，接 ESP32 输入 |
| SCK (PD_SCK) | GPIO 13 | 时钟输出，接 ESP32 输出 |
| E+ / E- | 称重传感器激励端 | 接 4 线制传感器 |
| A+ / A- | 称重传感器信号端 | 接 4 线制传感器 |

### 双层板走线提醒

- HX711 贴近称重传感器，传感器引线尽量短，减少长线干扰。
- DOUT/SCK 走线加地填充屏蔽，别和 12V 电磁阀 PWM 走线并行。
- 软件做滑窗滤波，板载 NTC 做温漂补偿（高中实验条件下先软件补偿）。

## 5. 12V 电磁阀驱动（核心创新：毫秒级防漏阀）

电磁阀额定 12V，用 NMOS 低边驱动，ESP32 PWM 控制栅极。

```
12V 电源 ──┬── 电磁阀线圈 ──┬── NMOS 漏极 (D)
           │                │
           │                └── NMOS 源极 (S) ── GND
           │
           └── 续流二极管 (反并联在线圈两端，阴极接 12V)
                   └── TVS 二极管 (吸收浪涌，并联在 NMOS 漏源之间)
```

| 元件 | 选型建议 | 说明 |
|------|----------|------|
| NMOS | IRF520N 或等效逻辑型 NMOS | 栅极阈值电压低，3.3V 能全开 |
| 续流二极管 | 1N4007 或 SS34 | 防止断电反电势击穿 MOS |
| TVS | SMBJ15CA 或等效 | 吸收感性负载浪涌 |
| 栅极电阻 | 100Ω | 限制栅极冲击电流 |
| 下拉电阻 | 10kΩ | ESP32 未上电时防止 MOS 误开 |

### 为什么低边驱动

NMOS 源极接地，漏极接电磁阀负极，栅极接 ESP32 GPIO。ESP32 输出高电平（3.3V）时 NMOS 导通，电磁阀通电吸合；输出低电平时断开，电磁阀断电，弹簧复位，锥形硅胶塞密封喉部。

### 双层板走线提醒

- NMOS 管尽量靠近电磁阀负极，续流二极管直接贴线圈两端焊接，引线越短越好。
- 12V 走线要走宽，不要和 3.3V 逻辑走线共用狭窄过孔。
- 电磁阀开关有火花，加 TVS 保护 ESP32 GPIO 和 NMOS 栅极。

## 6. 震动马达 PWM（关阀前 100 ms 震散卡沙）

扁平震动马达，PWM 调速，平时低功率破拱，关阀前 100 ms 满功率震散。

| 元件 | 连接 | 说明 |
|------|------|------|
| 震动马达正极 | 5V 或 12V（预留） | 取决于马达额定电压 |
| 震动马达负极 | NMOS 漏极 | NMOS 源极接地 |
| NMOS 栅极 | GPIO 15 (PWM) | ESP32 PWM 调速 |
| 去电容 | 0.1μF | 贴近马达负极，滤除 PWM 纹波 |

### 双层板走线提醒

- 震动马达是感性负载，加 0.1μF 去电容靠近马达，防止 PWM 开关纹波回耦到逻辑地。
- 震动马达 PWM 走线和 HX711 信号线分开，防止震动噪声干扰称重读数。

## 7. 传感器与安全（限位、急停、红外）

| 功能 | 元件 | 接 ESP32 | 说明 |
|------|------|----------|------|
| 限位开关 X | 微动开关 | GPIO 16 (INPUT_PULLUP) | 触发拉低，中断停止 |
| 限位开关 Y | 微动开关 | GPIO 17 (INPUT_PULLUP) | 同上 |
| 红外对管（堵料） | TCST1103 或等效 | GPIO 18 | 有沙堵塞时输出变化 |
| 急停按钮 | 大红蘑菇头按钮 | GPIO 19 (INPUT_PULLUP) | 最高优先级，硬件直接切断驱动 EN |

### 急停硬件逻辑

急停按钮不只软件检测，建议硬件上直接串联在步进驱动 EN 引脚或电磁阀 NMOS 栅极驱动回路上，按下立即切断所有驱动，不依赖 ESP32 软件响应。

## 8. 双层板走线与规则总结（给自己画板时看）

| 项目 | 规则 | 备注 |
|------|------|------|
| 板层 | Top 信号 + Bottom 地平面 | 或者反过来，保持一个完整地平面 |
| 板厚 | 1.6mm | JLC 标准双层板 |
| 最小线宽/间距 | 0.127mm / 0.127mm (5/5 mil) | 信号线足够 |
| 电源走线宽度 | ≥ 0.5mm (24V/12V) | 大电流走宽 |
| 过孔 | 0.3mm 机械孔 | 双层板不需要盲埋孔 |
| 丝印 | 嘉立创星火计划 Logo + 版本号 | 官方交付要求 |
| 表面处理 | 沉金 (ENIG) | 方便手焊 |

### 画板顺序建议

1. 先画板框（100×80mm，4 角 M3 定位孔）。
2. 放元件：电源模块靠近输入口，ESP32 居中，外设围绕分布。
3. 走电源：24V → 12V → 5V → 3.3V，走宽走短。
4. 走信号：HX711 → UART → GPIO，走短，远离大电流。
5. 铺地：Bottom 层大面积铺 GND，过孔多加接地。
6. DRC 检查，无错误后出 Gerber。
