# ESP32-S3 引脚分配表（v0.1）

> 主控：ESP32-S3-WROOM（1 GPIO 版或常用版，具体以实际模块为准）  
> 框架：Arduino IDE，`millis()` 轻量级多任务 + 状态机，**不使用 FreeRTOS**  
> PCB：嘉立创 EDA 专业版 **双层板**

| GPIO | 功能 | 方向 | 备注 |
|------|------|------|------|
| GPIO 0 | Boot 按钮 | 输入 | 上拉，进入下载模式 |

| GPIO 2 | 状态灯（WS2812 或 LED） | 输出 | 共用 1 线 |
| GPIO 4 | TMC2209_X_TX | 输出 | X 轴驱动 UART |
| GPIO 5 | TMC2209_X_RX | 输入 | X 轴驱动 UART |
| GPIO 6 | TMC2209_Y_TX | 输出 | Y 轴驱动 UART |
| GPIO 7 | TMC2209_Y_RX | 输入 | Y 轴驱动 UART |
| GPIO 8 | 步进使能 EN_X/Y（共用） | 输出 | TMC2209 EN 引脚 |
| GPIO 9 | 保留 / SPI Flash | — | 禁用 |
| GPIO 10 | 保留 / SPI Flash | — | 禁用 |
| GPIO 11 | 保留 / SPI Flash | — | 禁用 |
| GPIO 12 | HX711_DOUT | 输入 | 称重模块数据输出 |
| GPIO 13 | HX711_PD_SCK | 输出 | 称重模块时钟 |
| GPIO 14 | 电磁阀驱动 PWM（12V） | 输出 | NMOS 低边驱动，LED PWM |

## 电源与供电

| 网络 | 电压 | 供电对象 | 备注 |
|------|------|----------|------|
| VIN | 24V | 步进电机电源（TMC2209 VM） | 主电源输入 |
| 12V | 12V | 电磁阀线圈 | 板载 DCDC 24V→12V |
| 5V | 5V | 震动马达 / ESP32 5V 引脚 | 板载 DCDC 或 LDO |
| 3V3 | 3.3V | ESP32-S3 核心、HX711、逻辑电平 | LDO 输出 |

## 双层板走线提醒

1. **TMC2209 UART**：X/Y 各两根，走线短、远离高频 PWM 走线。
2. **HX711 信号线**：DOUT/PD_SCK 走线尽量短，加地填充屏蔽，避免干扰导致称重噪声。
3. **电磁阀 12V 驱动**：MOS 管靠近阀门负极，串联续流二极管，加 TVS 吸收浪涌。
4. **震动马达 PWM**：加 0.1μF 去电容靠近马达负极，减少纹波回耦到逻辑地。
