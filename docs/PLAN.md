## Phase 3：出沙头迭代 & 称重闭环标定算法（Week 5-7，Day 35-49）

### Week 5-6：出沙头 V1→V2→V3 快速迭代

| 版本 | 核心改进 | 打印/加工 | 验收指标 |
|------|----------|-----------|----------|
| V1 | 验证几何：倒圆锥喉部 30° + 锥形塞 + 硅胶垫 | SLA 树脂 (0.05mm) | 静止 1h 漏沙 < 0.1g |
| V2 | 加入震动马达卡位、红外对管槽、PTFE 喉管 | SLA + CNC 铝件喉部 | PWM 20%~80% 流量可控，无卡料 |
| V3 | 结构强化：电磁铁线圈固定座、弹簧预压可调、快拆硅胶管接头 | PETG-CF 打印件 + 标准件 | 振动测试 2g 无松动，拆装 < 2min |

> **每日站会节奏**：早 9:00 同步前日数据，定当日打印/加工/测试任务，晚 21:00 记录实测曲线进 Notion

### Week 6-7：称重闭环标定算法落地

| 任务 ID | 任务 | 技术细节 | 交付 |
|---------|------|----------|------|
| P3-01 | HX711 滑窗滤波 + 温漂补偿 | 200 样本滑窗均值 + NTC 多项式补偿 | 固件 `sensor/hx711.c` |
| P3-02 | 自动标定状态机 | 6 点 PWM 质量采集 → 三次多项式拟合 → Flash 存系数 | 固件 `service/calib_mgr.c` |
| P3-03 | 流量前馈查找表 | 目标流量 → 反查 PWM，线性插值，上电加载 | 固件 `service/flow_ctrl.c` |
| P3-04 | 标定异常处理 | R²<0.95/采样超时/传感器故障 → 报警并回退上次系数 | Web 告警 + 红灯闪烁 |
| P3-05 | 实机标定圆跑 10 次 | 不同沙批次/湿度/温度，记录流量重现性 | 实测报告 `docs/calib_report.md` |

**里程碑 M3（Day 49）**：出沙头 V3 定型，**流量重现性误差 < 3%**，零漏沙通过 24h 长跑 → **进入软件集成**
