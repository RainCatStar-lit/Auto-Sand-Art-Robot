# hardware

嘉立创 EDA 工程文件、原理图、PCB、BOM 放在此目录。

## 我的学习计划

由于此前未接触过 EDA 软件，本项目将作为我学习嘉立创 EDA 专业版（双层板）的实战练手。主控规划为 **ESP32-S3**，包含 HX711 称重模块接口、步进电机驱动接口（×2，CoreXY）和电磁铁控制接口。

80 天内我要完成：

1. 第一两周：跟通嘉立创 EDA 官方教程，建立元件库，画出 ESP32-S3 最小系统、HX711 接口、步进驱动接口、电磁铁驱动接口的原理图。
2. 第三四周：**双层板** PCB Layout，走线、过孔、铺铜，出首批 Gerber 送样。
3. 第五周起：收到 PCB 后焊接调试，根据实测迭代电路，直至整机通电。

## 目录规划（预计）

```
hardware/
├── eda/                    # 嘉立创 EDA 专业版工程源文件（双层板）
│   ├── schematic/          # 原理图
│   ├── pcb/                # PCB Layout（双层，1.6mm）
│   ├── lib/                # 自建封装与符号库
│   └── output/             # Gerber、钻孔、BOM、坐标文件
├── mechanical/             # 机电接口定义
│   ├── pinout.md           # ESP32-S3 引脚分配表
│   └── connector_map.md    # 连接器对应表
└── BOM_v0.1.xlsx           # 总 BOM（含采购链接、备选型号）
```
